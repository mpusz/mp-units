# Contributors

**mp-units** is shaped by everybody who works on it, whether by writing code, reviewing a
design, reporting the bug that exposed a flaw, or improving the documentation.

## Core Team

- **[Mateusz Pusz](https://github.com/mpusz)** - Creator and project lead. Core library
  design, and the C++ standardization effort behind it.
- **[Johel Ernesto Guerrero Peña](https://github.com/JohelEGP)** - Core maintainer. API
  design, code review, and the API Reference.
- **[Chip Hogg](https://github.com/chiphogg)** - Core maintainer. Unit magnitudes,
  compile-time arithmetic, and bringing proven ideas from the
  [Au library](https://aurora-opensource.github.io/au).

## Notable Contributions

A sample of what the community has built. Every release credits its contributors by name,
so the [Changelog](CHANGELOG.md) is the fuller record.

- **[burnpanck](https://github.com/burnpanck)** - Fixed-point arithmetic for integer unit
  conversions, overflow-safe cross-unit comparisons, the `value_cast` overloads, and the
  dynamically generated CI matrix.
- **[nebkat](https://github.com/nebkat)** - `atan2()`, `fmod()`, `remainder()`, and `ppm`.
- **[RalphSteinhagen](https://github.com/RalphSteinhagen)** - The HEP system.
- **[mikeford3](https://github.com/mikeford3)** - The FPS system, `si::angular_velocity`,
  and the absolute value math functions.
- **[kwikius](https://github.com/kwikius)** - Angle as an SI base dimension, and the
  `Quantity` concept refactoring of `math.h`.
- **[rbrugo](https://github.com/rbrugo)** - Named SI units and their dimensions, and
  localization support for text output.
- **[yasamoka](https://github.com/yasamoka)** - The STL random number distribution
  wrappers, ASCII-only output, and unit prefixes.
- **[hofbi](https://github.com/hofbi)** - `floor()`, `ceil()`, `round()`, and pre-commit
  support.
- **[go2sh](https://github.com/go2sh)** - `modulation_rate`, and the SI prefixes for
  IEC 80000.
- **[czjhoppe](https://github.com/czjhoppe)** - MSVC support for the library.
